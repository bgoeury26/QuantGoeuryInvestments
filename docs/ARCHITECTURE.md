## Data Models

### User
- `status`: PENDING → APPROVED (requires admin action)
- `role`: USER | ADMIN
- Settings stored encrypted in `UserSettings`

### Stock
- Universe of 25 tickers seeded at startup
- `scores[]` — time-series of computed `StockScore`
- `signals[]` — active `StockSignal` records (TTL-based)

### StockScore
Computed by `ScoringService.computeScore()`. Stores all 7 factor scores, `finalScore`, `confidenceFactor`, `anomalyScore`, and `rankingScore`.

### StockSignal
Generated by `AlphaService`. Each record has a `signalType`, `strength` (0–1), `earlyFlag`, `drivers[]`, and `expiresAt`.

## Scoring Engine V2

### Factor Weights

| Factor | Weight |
|--------|--------|
| Fundamental | 2.5 |
| Technical | 2.0 |
| Sentiment | 1.5 |
| Institutional | 2.0 |
| Analyst | 1.0 |
| Political | 0.5 |
| Macro | 0.5 |
| **Total** | **10.0** |

### Formula

```
weighted_sum = Σ(factor_score × weight) / 10
final_score  = weighted_sum × confidence_factor
```

### Confidence Factor (0.5 → 1.2)

Based on: data completeness, signal agreement, recency, noise/conflict.

```
confidence = 0.7 + completeness×0.2 + agreement×0.15 + recency×0.15 − noise×0.2
```

## Alpha Engine

The Alpha Engine detects **hidden signals before price moves**.

### Anomaly Detectors

| Module | Method | Description |
|--------|--------|--------------|
| Volume Spike | Z-score vs 30-day avg | Abnormal volume surge |
| Price-Volume Divergence | Price flat + volume rising | Accumulation indicator |
| Social Velocity | Mentions delta (Reddit/Bluesky/GDELT) | Attention spike |
| News Velocity | Article frequency burst | Media acceleration |
| Insider Cluster | Multiple buys within 30 days | Smart money signal |
| Institutional Rotation | Funds increasing position | 13F flow shift |

### Anomaly Score

```
anomaly_score = vol×0.30 + sentiment×0.25 + insider×0.25 + institutional×0.20
```

### Early Opportunity Flag

Triggered when:
- `anomaly_score > 0.45`
- AND `|price_change_24h| < 3%` (price has NOT yet moved)

### Signal Types

| Signal | Condition |
|--------|-----------|
| `SMART_MONEY_ENTRY` | insider > 0.6 AND institutional > 0.4 |
| `ACCUMULATION` | volume > 0.6 AND price_change < 2% |
| `MOMENTUM_IGNITION` | volume > 0.7 AND price up > 2% |
| `SENTIMENT_PUMP` | sentiment > 0.7 AND volume > 0.5 |
| `RISK_WARNING` | volume > 0.5 AND insider < 0.1 AND price down > 3% |

## Opportunity Ranking

```
ranking_score = final_score + 2.0 × anomaly_score + momentum_bonus
```

Top 10 ranked daily by `OpportunitiesService.getTopOpportunities()`.

## Caching Strategy

| Data type | TTL | Rationale |
|-----------|-----|----------|
| Quote | 5 min | Near real-time, rate-limited |
| Technicals | 1 hour | Intraday updates |
| Fundamentals | 24 hours | Changes quarterly |
| Analyst ratings | 1 hour | Daily updates |
| Macro indicators | 1 hour | Low-frequency |
| Sentiment | 30 min | Social data latency |
| AI analysis | 1 hour | Expensive to generate |

All caching is in-process (`Map`-based). Persisted scores are stored in PostgreSQL for historical trend analysis.

## Auth Flow

```
Register → status=PENDING → Admin approves → status=APPROVED → Login → JWT issued
                                                                         ↓
                                            JWT payload: { sub, email, role, status }
                                                                         ↓
                                            Frontend middleware validates on every route
                                            Backend JwtStrategy re-validates on every request
```
